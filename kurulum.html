Kurulum

Verinoda, küçük bir npm sarmalayıcısı olan bir Python paketidir. Zaten kullandığınız kurucuyu seçin.

uv tool install --link-mode copy "verinoda[precise]"

Yalıtılmış; gerekirse uv bir Python indirir.

pipx install "verinoda[precise]"

uv ile aynısı, pipx ile.

pip install "verinoda[precise]"

Geçerli ortama kurar (Python 3.10+).

uvx --from "verinoda[precise]" verinoda --version

Kurmadan bir kez çalıştırın.

İlk komutlar

  2. cd my-project && verinoda setup

    Kodu indeksleyin; kuruluysa Claude Code ve Codex'i bağlayın. Tekrar çalıştırmak güvenlidir.

  3. verinoda query "where is X configured?"

    Bir git projesindeki ilk soru indeksi kendiliğinden kurar.

  4. verinoda ui --graph

    Tarayıcıda notlar ve graf, yalnızca yerel.

  5. verinoda doctor --brief

    Kurulumu ve indeksin güncelliğini kontrol edin.

Gereksinimler

Python
3.10+, önerilen 3.12+ (çalışma zamanı izleyicisi sys.monitoring kullanır)
Platformlar
Windows 11'de test edildi; CI Linux, Windows ve macOS'ta
Ajanlar
Claude Code, Codex; setup --agents all ile Cursor, Gemini CLI, Copilot, Kiro ve diğerleri
Windows
winget install --id astral-sh.uv -e, ardından bir kez uv tool update-shell

npx hakkında

npm sarmalayıcısı hâlâ 0.4.0 sürümünde ve kendi numarasındaki PyPI sürümünü çalıştırıyor. Yani npx -y verinoda size 0.4.0 verir; komutları 0.5.0'ın README'sindekilerden farklıdır. 0.5.0 sarmalayıcısı yayımlanana dek pip, pipx veya uv kullanın.

Geliştirme sürümü

main dalını doğrudan GitHub'dan kurmak için (Windows):

uv tool install --force --reinstall-package verinoda --link-mode copy "verinoda[precise] @ https://github.com/Verinoda-Labs/verinoda/archive/main.zip"
