Mobile app

Talk Buddy

A voice-first, errorless, game-like learning app for children who need support with speech and language development.

Beta 0.9.0; not a diagnostic tool and no substitute for a specialist's assessment

Buddy asks a spoken question, the child answers by speaking, and the app judges the answer with tolerance for children's phonology. There is an Android app written in Flutter and a working browser demo that is a JS port of the lesson engine. It is a beta: the APK is signed with a debug key and has not been tried end to end on a real device.

Flutter (Android), Dart; HTML browser demo

Facts

  • Version Beta 0.9.0
  • No API key is bundled; first launch is offline and the whole lesson flow works without a key
  • AI chat is optional: the user enters a Gemini, Claude or OpenAI key under Settings > AI
  • The APK is signed with a debug key (not a Play Store release)
  • No Windows .exe; the desktop counterpart is the browser demo
  • The APK was built and its package info verified; it was not tried end to end on a real device
  • Building from source was tested with Flutter 3.24.x and JDK 17
