Claude Code skill and panel

Fable Orchestration

A Claude Code skill in which an expensive main model directs and work is spread across cheaper models by rank, and the panel that edits it.

The main loop runs on one strong but expensive model; it makes the plan, writes the briefs, takes the hard calls and does the final synthesis, and everything else goes to the cheapest rank that can carry it. There are eight ranks: Komutan, Baş danışman, Üçüncü görüş, Şeytanın avukatı, Subay, Astsubay, Er and İşçi. The model on duty in each rank is written in routing.json; the fable-routing panel reads and writes that file. Work can go to Claude sub-agents, Codex, the GitHub Copilot CLI and the Abacus.AI CLI.

Claude Code skill (SKILL.md and routing.json) and the fable-routing panel (/fable-panel)

Features

  • Ranks

    Komutan handles architecture, hard calls and the final synthesis; Baş danışman gives a second opinion on a hard call; Üçüncü görüş breaks a tie when two sides disagree; Şeytanın avukatı tries to break the plan, only on irreversible or high-stakes calls. Subay takes medium-hard work, Astsubay simple-to-medium work, Er execution when the operator wants work sent to the GPT side, and İşçi data cleanup of thousands of rows.

  • Panel

    Turns pools on and off, edits the order inside a rank and moving a model to another rank, and sets effort per model. The layout is saved to routing.json; when the table changes, a note is added to the operator's next message. The panel also shows how full the Claude and Codex windows are, the Abacus credits spent against the plan and the Copilot calls.

  • Brief shapes: loose for Subay (goal, context, constraints, what done looks like); a notch tighter for Astsubay (files, steps, output format, what not to touch); complete and step by step for Er; a peer-level question with evidence for Baş danışman; "break the plan, name the weakest assumption" for Şeytanın avukatı; one exact rule set, examples and small batches for İşçi. Long briefs go in a file.

  • Rules

    every call names its model explicitly; work goes to a rank by difficulty, and when unsure the cheaper one is taken and its result verified; the main loop keeps its context lean, and wide reading and raw data go to a delegate.

  • Verification

    a delegate's report is a claim; the diff, the output or a sample is checked before it is called done. Advisors agreeing is not proof, because models share blind spots.

Facts

  • Eight ranks: Komutan, Baş danışman, Üçüncü görüş, Şeytanın avukatı, Subay, Astsubay, Er, İşçi
  • Four model pools (Claude, Codex, Copilot, Abacus.AI); each pool has its own quota
  • The model on duty in a rank is the first model in its order whose pool is on
  • A model whose pool is off is never called
  • Advisor calls run read-only and never see one another's answers
  • The panel opens with the /fable-panel command
  • The expensive main model's work is judgment, not throughput

The skill is derived from the skill of the same name in Avenox's avenoxskills (MIT); the version in active use today was developed by Verinoda Labs. The fable-routing panel is Verinoda Labs' own work.
