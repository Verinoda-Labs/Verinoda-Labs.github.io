Claude Code mod

Verinoda Symbiosis

The same system, inside Claude Code. A mod that keeps the index fresh while Claude edits, nudges the agent to use it, and shows it all in a pane with an animated mascot.

Verinoda + Claude Code · Apache-2.0

Back to Verinoda

Why a mod?

In pre-registered studies with a model in the loop, an agent offered Verinoda used it in only 6 of 57 sessions. An index nobody calls and nobody refreshes is no help. The mod keeps it fresh and can put it in the agent's path.

What the mod adds to Claude Code.

  • Always-fresh index

    Every edit is noted; at the end of the turn one verinoda update --fast runs (about 20 s on 2,900 files instead of 130–155 s).

  • Agent nudges

    analyze, project_query and run_tool sit in the model's tool list, and one paragraph names analyze as the first call on a why, when or what-does-it-affect question.

  • Cards when compacting

    When Claude Code compacts the conversation, the summarizer gets one line per file read or edited: path, length, purpose, definitions, imports.

  • Edit check (off)

    /verinoda-check on: names on changed lines that exist nowhere in the project are told to the model. Off by default because it found nothing in measurement.

  • Live pane and mascot

    /verinoda-panel: a pane with the index state, the check setting and an animated purple mascot that reads the code while Verinoda works.

  • Answer language

    /verinoda-lang auto, tr, en or any language. Sent to the model only when it changes.

Inside Claude Code

Start with SYMBIOSIS.md in the repository; the mod lives in claude-mods/verinoda-live.

  2. pip install verinoda

    or: uv tool install verinoda

  3. cd your-project && verinoda setup .

    Builds the index

  4. claude --plugin-dir <repo>/claude-mods/verinoda-live

    Loads the mod into Claude Code

  5. /verinoda

    Ask the index from inside Claude Code

  6. /verinoda-lang tr

    Set the answer language

Measured

We measured the mod's effect in pre-registered studies with a model in the loop. The results are mixed, and all of them are published.

  • Small corpora

    The same facts; 16% fewer input tokens and 29% fewer tool calls (37–226 files).

  • Ten real repositories

    The same facts; 14% more input tokens and 16% fewer output tokens.

  • A stale index

    On projects of 300+ files a stale index cost about a fifth more input tokens; the fresh index the mod keeps removed that (in one of two runs).
