Webcord

Accountless voice and text chat. A nickname and a room code are enough; audio flows browser to browser.

Accountless voice and text chat. A nickname and a room code are enough; a static site with no server or build.

WebRTC · static

Features

  • Create a room, send the code or link to friends

  • Audio flows directly between browsers (WebRTC); nothing is recorded

  • For 2–6 people; screen sharing

  • Matching over public BitTorrent trackers (Trystero); you run no server

Anyone who knows a room code can join; share it only with friends.
