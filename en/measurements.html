Measurements

Performance claims are published only with their measurement. Everything below comes from the Verinoda repository's README (25 October 2026). Every row names a result folder.

In short

Without a model, Verinoda returns more of the asked-for facts per token than Graphify or plain search.

With a model in the loop (real Claude Code sessions), no measurement so far shows Verinoda improving the agent's outcome, and most measured a higher cost.

No model: how many facts, in how many tokens?

Retrieval only; tokens are chars/4. A gold fact counts when it is present in the returned text, not when a model uses it. Eight public sets, 86 questions, 319 gold facts.

ContextBench: a benchmark Verinoda was not developed on

80 instances in 8 languages, every output cut to 1,500 tokens. File recall: Verinoda query 0.570 · analyze 0.453 · Graphify 0.404 · BM25 0.370.

The “N times fewer tokens” headline

Graphify's README says “71.5x fewer tokens per query vs reading the raw files” (on 52 files). That figure is the corpus's tokens divided by the answer's tokens. The same division on the eight sets gives 281x for Verinoda's query and 92x for plain search. The multiple grows with the size of the test corpus, not with the tool. No agent reads every file, so we headline no multiple: facts per token at one budget, above, is the comparison.

Fixes the studies led to

  1. 1,600 → 70

    A session opened outside a project no longer carries Verinoda's tools and rule: tokens per request.

  2. 4.8 → 0.4 s

    A scripted session's exit no longer waits for the mod's re-index (median on the six fix tasks).

  3. 6,577 → 703

    The index_update record an agent reads shrank by this many tokens.

  4. 55 → 6.6 s

    On django the refresh is 6.6 s inside the call instead of a 55 s background graph build.

Not measured

  • A task where Verinoda changes an agent's result: none found yet; every outcome study sits at the agent's own ceiling or within chance.
  • Tasks fixed after the models' training data (the held-out SWE-bench run was cancelled).
  • Codex sessions with the D186 skill.
  • A real tokenizer for the no-model tokens (chars/4 for now).
  • The person's hand check of the false-claims judge.

Every row points to a result folder under benchmarks/results/ in the Verinoda repository. Where a study leaves out its session transcripts or logs, its results README says so. The private-repository study's tasks, data and transcripts are not published.
