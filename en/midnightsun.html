Windows desktop app

MidnightSun

Low-latency game streaming for Windows: NVENC, a custom UDP protocol (GSMR), Opus audio and a keyboard, mouse and gamepad back-channel.

Version 1.0.0; per the README, end-to-end streaming between two computers was not tested separately

Lets you play a game or the desktop of a powerful Windows PC from another computer on the same network. Video is compressed with NVENC without leaving the GPU and audio travels as Opus. One MidnightSun.exe plays both the host and the viewer; there are no accounts, no cloud server and no telemetry. No latency figures are published.

C++, DirectX 11 / DXGI, NVENC, Opus, UDP (GSMR)

Facts

  • Opus audio, 20 ms
  • No accounts, cloud server or telemetry
  • Automatic discovery on the same network; a XXXX-XXXX-XXXX pairing code for other network segments
  • Optional end-to-end encryption: AES-256-GCM when both sides enter the same PSK
  • 256-key keyboard bitmask, 5-button mouse, XInput gamepad (virtual Xbox 360 pad via ViGEmBus on the host)
  • The host needs an NVIDIA GPU with NVENC (GTX 10xx+, driver 522.25 or newer); Windows 10/11 x64
  • Defaults: 20000 kbps maximum bitrate, 1080p, 60 FPS, port 9000
  • IPv4 only, no NAT traversal (LAN, VPN or port forwarding needed)
  • The app and installer are not code-signed (a SmartScreen warning is expected)
  • Verified: clean build from source, the portable exe starting, the launcher and settings screens. The installer was not installed and tried on that machine.
