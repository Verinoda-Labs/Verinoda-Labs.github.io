Install

Verinoda is a Python package with a small npm wrapper. Pick the installer you already use.

uv tool install --link-mode copy "verinoda[precise]"

Isolated; uv fetches a Python if needed.

pipx install "verinoda[precise]"

The same with pipx.

pip install "verinoda[precise]"

Into the current environment (Python 3.10+).

uvx --from "verinoda[precise]" verinoda --version

Run once without installing.

First commands

  2. cd my-project && verinoda setup

    Index the code and connect Claude Code and Codex if installed. Safe to re-run.

  3. verinoda query "where is X configured?"

    The first question in a git project indexes it by itself.

  4. verinoda ui --graph

    Notes and graph in the browser, local only.

  5. verinoda doctor --brief

    Check the install and index freshness.

Requirements

Python
3.10+, 3.12+ recommended (the runtime tracer uses sys.monitoring)
Platforms
Tested on Windows 11; CI on Linux, Windows and macOS
Agents
Claude Code, Codex; Cursor, Gemini CLI, Copilot, Kiro and more via setup --agents all
Windows
winget install --id astral-sh.uv -e, then run uv tool update-shell once

About npx

The npm wrapper is still 0.4.0 and runs the PyPI version of its own number. So npx -y verinoda gives you 0.4.0, whose commands differ from the 0.5.0 README's. Until the 0.5.0 wrapper is published, use pip, pipx or uv.

Development version

To install main straight from GitHub (Windows):

uv tool install --force --reinstall-package verinoda --link-mode copy "verinoda[precise] @ https://github.com/Verinoda-Labs/verinoda/archive/main.zip"
